# Mentiora Tracing SDK

Public SDK for external clients to send agent traces to the Mentiora platform.

## SDKs

- [`typescript/`](./typescript/) - TypeScript/JavaScript SDK
- `python/` - Python SDK (coming soon)

## Quick Start

### TypeScript/JavaScript

```bash
npm install @mentiora/tracing-sdk
```

See [typescript/README.md](./typescript/README.md) for usage.
