# Mentiora SDK

Official SDK for the Mentiora platform. Provides access to platform features including tracing, vector database operations, and more.

## SDKs

- [`typescript/`](./typescript/) - TypeScript/JavaScript SDK
- `python/` - Python SDK (coming soon)

## Features

- **Tracing**: Send agent traces to the Mentiora platform for observability and debugging
- **Vector DB**: Upload, manage, and query files in the vector database (Qdrant) - coming soon
- More features coming soon

## Quick Start

### TypeScript/JavaScript

```bash
npm install @mentiora/sdk
```

See [typescript/README.md](./typescript/README.md) for usage and API documentation.
